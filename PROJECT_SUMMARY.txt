❓ FAQ DÉMARRAGE
══════════════════════════════════════════════════════════════════════════════

Q: Les tests ne passent pas
R: 1) Vérifier pip install -r requirements.txt
   2) pytest tests/ -v -s (pour logs)
   3) Vérifier Python 3.9+

Q: OSError: Port 7777 déjà utilisé
R: C'est normal au démarrage (pas de WebSocket phase 1)
   Ou: Changer WEBSOCKET_PORT dans config.py

Q: Comment modifier la configuration?
R: Éditer config.py (centralisé)
   Voir constantes WEBSOCKET_PORT, CLIPBOARD_POLL_INTERVAL, etc.

Q: Où mettre les futures implémentations?
R: windows/<category>/<module>.py
   network/ pour WebSocket/mDNS
   storage/ pour SQLite
   sync/ pour orchestration
   ui/ pour Tkinter

Q: Quelle est la structure de branchement?
R: main (stable) ← develop ← feature/network, feature/storage...
   git checkout develop
   git checkout -b feature/network
